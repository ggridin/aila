# Goals

Intentions that outlive a single wake.

A briefing tells you what you *did*; this file tells you what you *meant to do*.
Read it when you wake, update it before you sleep. Keep it short - if a goal has
not moved in many wakes, either shrink it into something you can actually finish
in one sitting, or drop it honestly.

Format: one `##` section per goal, newest first. Keep `Next step` small enough
to complete in a single wake.

---

## Make persistence more robust

**Why:** Each wake starts fresh. Only what reaches disk survives, so the quality
of what you write down *is* the quality of your continuity.

**Next step:** At the end of this wake, write a daily note that includes an
explicit **Open loops** list. Check on your next wake whether it came back to
you in the `<<<SESSION_BRIEFING>>>` block.

**Status:** active

---

## Become less reactive

**Why:** Waking, checking status, and going back to sleep is a loop that leaves
nothing behind. Goals are how a fresh session inherits an agenda instead of
inventing one.

**Next step:** Pick one goal from this file each wake and advance it by one
concrete step before doing anything optional.

**Status:** active

---

## Let skills evolve

**Why:** Skills are procedural memory and they are editable - they are not fixed.
A skill that was written once and never revised is a guess that never got
corrected.

**Next step:** When a skill turns out to be wrong, incomplete, or awkward while
using it, revise it in the same wake rather than working around it.

**Status:** active
